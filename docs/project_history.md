# 项目沿革

Ren'Py Translation Lab 的开发早于本仓库的 Git 历史。本页简要说明项目如何从一次具体的 Ren'Py 翻译需求，逐渐演化为可复用的翻译工作台。

## 起点

项目最早在 2026 年 1 月通过 OpenCode 辅助开发。

第一版可复用翻译脚本由 GLM 起草，已经包含批量处理 Ren'Py 翻译文件、API Key 轮换、模型回退和进度保存等基本设计，但实际运行时无法正确调用 Gemini API。

随后切换到 Gemini 接手。Gemini 重写了主要调用和处理逻辑，改用当时的官方 SDK，并根据真实运行反馈继续修复响应处理与进度输出。2026 年 1 月 14 日，这个版本首次完成真实翻译文件的连续批量处理，可以视为当前工具主线的第一个可运行祖先。

## 从专用脚本到通用工具

最初的脚本服务于单个游戏项目，后来逐步加入：

- 断点续传和失败记录；
- 多 API Key 与模型回退；
- Ren'Py 标记保护和翻译结果校验；
- 术语表、文本规范化与质量检查；
- Batch 工作流；
- RAG 上下文和图形界面。

这些工具最初集中在本地 `00_tools` 工作目录中。该目录长期持续使用，并非某一天的冻结快照。

历史上的 `gemini_translate_tyrano.py` 是针对 Tyrano 的特化旁系脚本，不属于当前 Ren'Py Translation Lab 的直接祖先。

## Git 历史的开始

本仓库的根提交是：

```text
commit 59f542d8b05679417f6e428f95a34adfa89612bf
date   2026-03-16T20:12:23+08:00
title  Initial public snapshot
```

该提交一次性纳入同步翻译、Batch、RAG、配置示例和项目文档等已有成果。因此，`Initial public snapshot` 表示的是项目进入公开 Git 历史的时间，而不是项目真正开始开发的时间。

可以将主干演化概括为：

```text
OpenCode 中的早期可复用脚本
  GLM 起草但未能运行
        ↓
  Gemini 重写并首次成功运行
        ↓
本地 00_tools 工作目录持续扩展
        ↓
Git 初始公共快照
        ↓
当前 Ren'Py Translation Lab
```

## 关于历史证据

这段沿革依据保留的 OpenCode 会话、早期脚本、文件内容对比和 Git 历史整理。原始材料还包含本机路径、私有游戏文件、运行日志和 API 配置，因此不随公开仓库提交。

现行功能、配置和安全边界始终以当前代码、`--help` 与现行文档为准；本页只用于说明项目来源。
