**本轮完成 B0 的只读盘点，并冻结首个候选交付单元 C0 的源位置清单。**
C0 是“启动／教程＋序章，直到转入下一幕之前”的静态交付建议；尚未确认发行版所有可达路线，
不能称为首章或全游戏已验收。此前 A4 的 101＋7 已完成真实翻译、Agent 审阅和安全写回；
本轮新增 Provider 调用、游戏写入、原生启动均为零。原生验收继续按用户安排后置。

## 2. C0：首个完整交付单元的候选范围

在进入下一幕的地图转移处结束。共 7 张运行候选地图、413 个事件页；编辑器分组用的空地图
没有并入派发范围。完整 typed JSON 路径、文件／字串 SHA-256、事件条件、唯一出口和入边均留本地。

| 内容 | 已固定的静态范围 | 尚待确认 |

| 标准叙事 | **2,788** 个非空主要位置，其中 55 个选项；**55** 个镜像，共 2,843 个字符串叶位置 | 点击条件和各分支的实际到达、语义审阅与屏幕验收 |

本地已生成与现行 schema 1 范围格式兼容的候选 occurrence 文件，只列主要位置，镜像保持 Adapter 联动。

本轮没有把该清单接入项目配置、导入覆盖批准或创建付费任务。当前待译数和费用须由未来目标副本的

## 4. 图片文字是独立范围

对包内全部 **501 个 PNG** 建立摘要、尺寸和引用清单，宿主 Agent 检视 8 张覆盖全部资产的缩略图表，
并对 UI 按钮和使用中的图集区域补查。确认 **至少 154 个资产含文字或字母缩写**；
其余 347 个只表示缩略图未观察到文字，不能据此认定不含小字、背景标牌或嵌入文字。
没有生成全量 OCR 文本，也没有人类复核；尚不能给出图片文字的句数／区域总分母。

| 已确认的图像类别 | 资产数 | 处理决定 |
| --- | ---: | --- |
| 日记正文 | 21 | 确有成段英文烘焙于图片；包含旧变体，按真实引用与发行范围判断，不能由文件名直接排除 |
| 引语／诗句卡 | 28 | 是可见叙事的一部分，须独立转录、审阅与排版 |
| 日期、章节／场景标题卡 | 23＋26 | 按场景引用保留资源身份和演出时序 |
| 点击背景／覆盖标签、启动通知与按钮、消息按钮 | 21 | 文字需与点击区域、按钮状态和原尺寸一致 |
| 演职员、音乐署名、创作者／引擎品牌 | 31 | 逐项决定翻译说明与保留人名／品牌，不把所有字母自动汉化 |
| 角色脸图、战斗／图标字母 | 4 | 按实际使用区域审查；C0 使用到的图标区域已补查为图形，不因图集别处有字而整图改写 |
| 合计 | **154** | 是确认含文字的资产下界，不是必须翻译资产总数 |

C0 的 15 个直接引用文字资产包括日期、引语、点击背景／覆盖词、启动提醒与按钮、标题卡和创作者署名。
插件另外按资源名加载消息按钮。仅修改 JSON 或字体不能翻译这些像素文字。
全包 8,709 次 Show Picture 中，8,688 次能对应现存 PNG；其余 21 次引用只出现在当前未连通的测试地图，
按未知／待判保留，没有修改名称或复制其他素材填补。音频资源也只作清单保留，没有转写或修改。

## 5. 中文字体与最小能力缺口

13 份随包字体的 Unicode cmap 均没有基本汉字区字形。CSS 的 GameFont 指向原随包西文字体；
当前 locale 走 GameFont 分支，消息插件字体参数为空、字号 36。不能依赖“系统可能 fallback”作为交付方案。

本机 Noto Sans SC 候选文件的 cmap 覆盖已审阅 A4 译文中全部 **536 个非 ASCII 码点**，
但其文件版本标记为 non-release，仅作为静态探针，未复制进目标游戏。
后续应从官方来源固定可复现字体包、SHA-256 和许可副本；
[官方元数据](https://github.com/google/fonts/blob/main/ofl/notosanssc/METADATA.pb)和
[OFL 1.1 许可](https://github.com/google/fonts/blob/main/ofl/notosanssc/OFL.txt)已核对。
字体随软件提供时保留版权与许可说明。本轮未证明该本机文件与官方包逐字节一致，
也没有全 C0 译文字形、NW.js 字体加载、性能、换行或气泡布局的运行证据。

| 后续工作 | 最小交付与验收 | 与 C0 的关系 |
| --- | --- | --- |
| 字体与布局 | 固定中文字体、许可和摘要，在独立目标上验证正文／选项／回顾／存档；保留原布局资源，记录可恢复变更 | 中文显示的前置，不由 cmap 通过代替原生显示 |
| 显示字段与 UI | 优先盘清 7 个地点名及实际使用的存读档／设置词；MV 增加显式字段白名单并复用公共 schema 2 字符串写回，按现有约定同步 CLI／GUI／检查 | 公共 JSON 合同可表达这些叶子，但当前 MV Adapter 不接受这些新增显示字段的翻译；不能手工绕过结构门禁 |
| 图片文字 | 先转录并独立核对 C0 所需图像区域，明确品牌保留项，生成目标专用资产方案；保留尺寸、透明度、热点与按钮状态，逐资产绑定摘要和恢复证据 | C0 完整交付必须处理实际可见图片字；日记等后续章节内容继续留在全包缺口账 |
| 插件显示 | 固定必要界面字串与资源消费者，核查按钮真值／键名差异；显示补丁与 core／插件摘要窗口一并审计 | 不使用全局 JS 搜索替换，不通过关闭窗口校验引入补丁 |
| 运行与范围 | 先补 A4 的 S1–S3、五分支、字体、回顾及保存后重启读取；再确认 C0 的条件、出口与图片可见性 | 通过后才确认里程碑 A，并冻结真实首章的完整分母、模型与预算 |

本报告交付调查和可审查的任务边界，没有实现上述能力，也没有自动创建 issue、提交或 PR。
当前需要的是显示与范围补齐，未发现必须先扩展新 Provider、Batch、外部 Agent 工作包或重构上下文系统的证据。
