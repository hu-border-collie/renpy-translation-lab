## 独立分母和原始失败

采用 #565 在 Adapter 实现前冻结的 S1–S3 清单：94 条对白、7 个选项、7 个 402 镜像。
原调查的 20 个手选位置重新核对通过；全材料 30,931 个原始物理位置与独立调查逐位置、
逐原文字串一致，21,956 个暂不支持的指令位置也独立对账。没有以去重原文数作为分母。

首次真实预检保留为失败记录，暴露了三处缺口：

- 一处整数取消索引超过选项数，实际冻结 core 的 `setupChoices` 会按 -2 理解，原 Adapter
  将其判为非法参数并提前结束扫描。
- 一处反斜杠后接 ASCII 空格的原始写法未登记，完整材料检查保持阻断。
- 三张试点地图按文件过滤会选中 173 条，超出独立清单的 101 条，不能直接付费派发。

本地修复保留原取消参数，明确保护反斜杠与 ASCII 空格，并增加
[精确位置范围文件](../rpgmaker_mv_sync.md#精确位置范围可选)。清单绑定完整源文件和原文字串摘要，
与配置、覆盖审阅、源／目标和结果一起参加派发、check、apply 身份校验。
完整材料始终审计，样本外未知控制码仍会阻断；没有删文件、清洗原文或关闭门禁。
core 的版本声明冲突仍按原报告保留，支持窗口继续限定实际 core／插件摘要。

## 真实结果、审阅与费用

请求模型沿用本地 `deepseek/deepseek-flash`，用户授权本轮费用上限 US$1。
初译和订正共保存 4 个耐久运行；16 个执行器 attempt 中，13 个成功返回 usage，
3 个为服务不可用失败，无 outcome-unknown。失败未返回 usage，未据此认定为零费用。

宿主 Agent 逐项审阅 101 对原文／译文，处理普通英文残留、术语／名字别名和语境、主语、
习语等问题。首轮风格文件因放在项目目录外被路径规则忽略，纠正位置后重新执行；首轮
结果与失败记录保留。后续两次定点派生分别复用 97／100 条，其余由真实 Provider 重新生成，
没有伪造成功响应或改写旧 winner。最终语义审阅绑定最终 run 和 results 摘要，reviewer 如实记为 Agent。

所有派生运行从 US$1 中扣除此前全部保守预留，再使用共享执行器的原子成本门禁。
累计保守预留 **US$0.84702022**。按已返回 token、缓存命中和
[当日官方非高峰定价](https://api-docs.deepseek.com/quick_start/pricing/)估算为 **US$0.03689010**；
3 次失败没有 usage，实际账户扣款未核对，不能将该估算写成账单实付。
