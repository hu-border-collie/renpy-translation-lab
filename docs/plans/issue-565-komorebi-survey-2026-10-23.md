## 1. 路线决定与证据边界

**继续原生 JSON 路线的公共合同设计，首期缩小到本次冻结的 Komorebi MV 数据包及其叙事参数。暂不宣称支持一个通用 MV 版本，不立项 MZ，也不恢复 Translator++ 生产 bridge。**

真实需求与可读的未加密数据已具备。主要叙事候选在标准事件参数中，插件对消息呈现和控制码有实质影响；这足以推进下述 P1 合同设计，但不是生产 Adapter、中文可运行或第三 Adapter 最终选型完成的证据。原生补证以后仍可收缩或暂缓。

本轮只读原件和既有工作副本，不执行插件取得清单，不翻译、不修改游戏、不生成存档、不调用翻译 Provider。两次 Computer Use 启动均返回 `Computer Use app approval timed out`，随后窗口列表未出现游戏。该结果是应用访问授权未完成，**不是观察到了游戏崩溃**。用户随后明确选择先完成离线调查；没有用 HTML5 运行替代原生验收。

公开数据见[脱敏元数据](issue-565-materials/public-metadata.json)及[材料说明](issue-565-materials/README.md)。精确本机路径、私有对白、脚本参数、源位置清单和运行工具记录仅在 Git 忽略的本地证据目录保留。

### 3.1 控制码与取消行为

对 401、102 和 402 的原始字符串扫描到 `\pop[arg]` 18,058 次、`\i[arg]` 4,562 次、`\c[arg]` 10,852 次、`\C[arg]` 4 次；**这些计数包含 402 镜像**。另有一处反斜杠后紧接空格的异常线索，已单独留本地，不能猜测归一化后写回。

首期最小集合为 `\pop[...]`、`\c[...]` / `\C[...]`、`\i[...]` 和普通文本。`\pop` 的目标参数、所属消息块及首行位置有呈现语义；保留原始大小写、参数、顺序和归属。原件存在未闭合颜色使用，不能照旧笔记无条件“成对补全”。变量 / 姓名 / 货币码在已扫描叙事原文中未出现，不据此宣称已实现支持；用原创 fixture 验证或先阻断相关项。

取消设置不是一种情况：1,465 条 102 禁止取消；4 条测试地图指令把取消映射到已有选项；另 1 条单选项指令的取消值超出选项数，core 会归一化为 -2。全包没有 403 指令。该单选项取消路径不在首个试点，也未运行确认；不得虚构“已覆盖独立取消分支”。

### 4.1 后续真实小样本验收办法

1. **机械核对**：原始独立清单作分母，101 项全量核对、7 个 402 关联目标同步；保存消息块和 570 个空消息的既有结构。所有非目标参数、事件页条件、转移、变量、资源和插件状态保持原样。
2. **原生可达性**：从工作副本正常入口进入 S1–S3；在 S1 确认前、S2 选项前、S3 开始分别建立独立检查点。五个分支分别读取 / 执行，记录对应位置，保留必要的未译基线。
3. **显示与字体**：13 份随包字体的 cmap 均无基本汉字区字形；GameFont 指向 Metropolis，插件字体大小为 36。系统 fallback、实际字形来源、换行和气泡尺寸均未验证。中文字体应在受控目标副本单独准备并记录许可 / 摘要，再检查文字、选项、回顾、按钮和存档界面；不把“字体文件存在”当显示通过。
4. **存读档与恢复**：在上述检查点保存、关闭后重启读取，核对选择回调、变量 / 页状态和回顾；保留未译存档兼容与新译存档两种情况。现有存档插件需随原包测试，HTML5 检查不能代替。
5. **译文质量**：后续翻译由独立审阅检查语义、说话者、术语、口吻、选项意图与跨场景一致性；机械 `check=allow` 与原生可运行都不等于译文质量通过。本轮没有产生或评审译文。

## 5. 首期输入窗口与原创 fixture

首期窗口只接受本次源材料摘要对应的 MV 数据和已登记 `GALV_MessageStyles` 2.8 控制码。输入为冻结源目录、单独目标游戏副本、二者当前摘要、叙事 occurrence / 消息块清单及独立译文记录。MZ、任意 MV 项目、插件源码 / 参数改写、数据库 / 系统全量翻译、图像文字、音频、未知脚本和原包覆盖不在首期。

私有游戏不能直接作为公开回归 fixture；#509 的 MV 1.5.1 覆盖层只复用其独立记账方法与许可明确的原创材料，不移植其引擎 / 版本结论。后续 P2 至少需要以下原创 JSON 数据覆盖层，实际运行包由有权运行的目标环境另行组装：

- 101 / 401 单行、多行、空消息；同文不同人物 / 情境分别定位，不按原文合并。
- 102 多选项、402 标签镜像、禁用取消、映射选项、独立 403 取消，以及越界取消值的显式拒绝或记录。
- 多事件页条件、公共事件被不同调用点引用、角色名修改；变量 / 姓名 / 图标 / 颜色 / popup 参数和大小写、未知 / 畸形控制码。
- 插入指令、事件 / 页重排、相同文本的歧义、源更改、当前目标更改、重复 / 冲突提交和旧结果 stale。
- 数组索引与字符串键区分、null / 非字符串叶子、负数 / 越界索引、空目标及空译文政策、UTF-8 / BOM / 换行与转义。
- 未选 JSON 字段和非 JSON 资源保护、序列化语义差分、写入失败后的原字节恢复、兼容读取旧公共计划。

### 6.1 最小写回和持续翻译约束

- 冻结英文源与目标当前值、译文账本分开。首次写入中文后，下一轮仍从可信冻结源识别原文，不能把已译目标再次当新源；游戏更新建立新快照和对账记录。
- 源文件、目标文件和目标当前字符串各自绑定摘要。事件 / 页 / 指令下标仅在该快照内有效；发生插入、移动或歧义时旧结果 stale，不因相同原文就自动重新关联。
- 新操作只准写受控目标副本中已经存在的字符串叶子，严格区分字典键和非负整数索引；不创建父节点，不改变数组结构，不把 null / 数值当文本。布尔值不能冒充整数索引。空消息保持；空译文等政策需在新合同中显式决定，不能放松旧 catalog 合同。
- 原文件字节摘要、JSON 解析语义、序列化输出和恢复字节分别定义。无修改结果不应重新序列化整个文件；翻译写回只有获准字符串可改变，其他结构做独立语义差分，失败恢复保留原始字节。
- 复用现行检查 / 预览 / 安全写回链，不另写私人 JSON writer。最近检查必须与当前材料和结果匹配；`force` 不能绕过 stale、源快照或结构阻断。质量报警默认不阻断，项目配置提升为 blocker 时必须阻断。
