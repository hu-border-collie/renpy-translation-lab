# #567 B0 公开材料

本目录承接 [B0 只读范围与显示盘点](../issue-567-b0-scope-audit-2026-10-25.md)。
[public-metadata.json](public-metadata.json) 保存固定材料身份、包内计数、静态分组、C0 候选范围、
已确认图片文字下界、字体探针和未完成验收，便于核对报告。

公开文件不包含私有对白、图像、脚本、精确事件路径、存档或本机游戏路径。
原始地图／事件条件、独立位置清单、源和字串摘要、图像引用、缩略图、字体元数据及调查脚本只保留在本地制品中。
JSON 是调查汇总，不是产品配置、覆盖审阅批准、翻译结果或可直接使用的写回计划。

计数口径：

- narrative 和 groups 按标准 401／102 物理位置记账，402 镜像与空消息分列，重复原文不合并。
- direct_transfer_graph 展开所有页和分支，只说明静态连通，不证明运行可达或获准排除未连通内容。
- candidate_C0 是启动／教程＋序章的候选边界；其主要位置、镜像、图片资产及显示字段是不同分母，不能相加为“总句数”。
- images 的 154 是经宿主 Agent 缩略图审阅确认含文字的资产下界。其他资产未观察到文字不等于已确认无字；没有全量 OCR 或人类复核。
- non_narrative 的原始 JSON 字符串已按存储角色分桶，动态可见文本仍未穷举。显示候选不是已批准翻译项。
- fonts 只表示静态 cmap 探针；本机 non-release 文件没有打包。官方字体来源／许可和原生显示需要按报告后续工作处理。

本轮新增 Provider 调用、游戏写入、原生启动均为零。发行路线、首章完整分母、里程碑 A／B 均未验收。
